\# Отчет по безопасности (Security Findings)



В рамках практической работы 01 были выполнены следующие проверки:



1\. \*\*Защита ветки `main`:\*\*

&#x20;  \* Настроен запрет на прямой `push` (подтверждено: при попытке push в main получена ошибка `remote rejected`).

&#x20;  \* Настроен запрет на `force push` (принудительный пуш).

&#x20;  \* Настроен запрет на удаление ветки.

&#x20;  \* Слияние возможно только через Merge Request.



2\. \*\*Секреты и токены:\*\*

&#x20;  \* Токены и пароли не хранятся в репозитории (файл `.gitignore` исключает локальные настройки).

&#x20;  \* `docker-compose.yaml` не содержит реальных паролей (только токен для регистрации агента, который не является секретом проекта).



3\. \*\*Анализ зависимостей:\*\*

&#x20;  \* Сборка Maven проходит с проверкой зависимостей (в рамках `mvn clean verify`).
